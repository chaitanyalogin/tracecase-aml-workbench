# TraceCase: an AML work sample

This AI-assisted independent project uses fictional evidence to practise entry level transaction investigation. It does not represent work for a bank or access to a licensed screening platform. Candidate-authored case conclusions should be assessed separately from the application and its author-written learning aids.

## The operational problem

An alert identifies activity that differs from an expected customer profile. The analyst needs a clear evidence packet, consistent calculations and a defensible explanation of whether the concern is resolved, needs more information or requires internal escalation. Similar transaction patterns can have different explanations.

## The two investigation exercises

| Case | Activity to examine | Reasoning to demonstrate |
|---|---|---|
| C001 | Salary-only profile, multiple non-routine payers, closely following debits and an unverified collection explanation | Identify material information gaps without treating a customer statement as corroboration or declaring criminal conduct |
| C002 | Property sale receipts and mortgage redemption with matching fictional verification records | Assess legitimate explanations and document why numerical similarity alone does not determine an outcome |

All verification assertions are fictional scenario records. There is no live registry or screening connection.

## Evidence of analyst skills

| Skill | Work product to inspect |
|---|---|
| Customer understanding | Explanation of expected activity and why the activity differs |
| Transaction analysis | Correct amounts, dates and parties tied to transaction identifiers |
| Evidence assessment | Clear distinction between verified, unverified and missing information |
| Critical thinking | Legitimate alternatives, contradictory evidence and questions that would change the decision |
| Assisted analysis | Review of every cited factual claim; reference existence is not treated as factual correctness |
| Written communication | Concise investigation rationale with a justified next action |
| Documentation | Exported report, selected evidence and reproducible snapshot identifier |

## Candidate hand-in

Complete one report for each case in your own words. Include: trigger, material facts and references, checks performed, unresolved questions, legitimate alternatives, decision and next steps. Explain the limits of the evidence. Do not copy coaching and present it as independent investigation work.

Use `FIRST_SESSION.md` to begin. The application includes a downloadable Markdown investigation report and JSON evidence/history for closer review.

## Honest limitations

This is a learning demonstration with two cases, not an independently validated AML control. It has no live sanctions feed, automated account restrictions, regulatory filing capability or authenticated reviewer sign-off. The optional AI provider has not been tested with paid live requests. Public session storage is temporary. These limits are intentional and documented.
